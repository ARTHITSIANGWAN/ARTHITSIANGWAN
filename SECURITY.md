## 🚨 Reporting a Vulnerability
If you discover a security vulnerability within any ThitNueaHub repository, please report it directly through secure channels:
* **Admin Contact:** Arthit Siangwan (Owner & Sovereign Architect)
* **Response Time:** Critical vulnerabilities are reviewed within 24 hours.
* **Scope:** Any unauthorized access attempts, DB locking flaws, or token bypasses.
